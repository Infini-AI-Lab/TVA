# Vector addition (tutorial 01)

The prover's write-up. The claim the reviewers judge is [claim.md](claim.md) (generated by `tvr check`); the review
is [REVIEW.md](REVIEW.md) (generated from `review/`). Device facts and their evidence are the library's.

Lean: [`lean/VecAdd.lean`](lean/VecAdd.lean). Source: [`source/01-vector-add.py`](source/01-vector-add.py) (`add_kernel`),
launched with `grid = (cdiv(n_elements, BLOCK_SIZE),)`.

## Specification

`Post d init fin`:

- for every `i < n`, the output element `out[i]` in final memory is the IEEE sum `x[i] + y[i]`
  of the inputs in initial memory (round to nearest even), up to the NaN payload;
- every byte outside `out` is unchanged.

`Spec K := Claim.Meets Inst.ok Pre Post K`. On every covered instance and every input
satisfying `Pre`, every outcome the device may produce satisfies `Post`.

## Conditions

`Inst.ok` (the instances covered):

- `0 < BLOCK_SIZE`, and `BLOCK_SIZE` is a power of two of at most `2^20` (Triton's block limit);
- `n + BLOCK_SIZE ≤ 2^31`, so the `int32` offsets `pid * BLOCK_SIZE + arange` do not overflow;
- `x`, `y` and `out` each have `n` elements;
- `out` overlaps neither `x` nor `y`. The inputs may overlap each other.

`Pre` (the inputs): the three buffers are valid (aligned and present). The values are
arbitrary: NaN and infinities are covered.

## Assumptions

- `Compiler.Faithful`: the compiled kernel behaves as the model under the launch. This is the
  library's one compiler rule ([rules/compiler-faithful.md](../../docs/rules/compiler-faithful.md)).

No numeric rule is needed. `x + y` has no product as an operand, so it is plain IEEE addition
(`tl.add`).

## Proof

- **Per program** (`main`, first goal):
  - program `p` loads its masked block of `x` and `y` (`safe_load_block`), adds, and stores
    (`safe_store_block`);
  - its footprint is the tile `[p·B, (p+1)·B) ∩ [0, n)` of each buffer.
- **Footprints**: different programs write different tiles of `out`, and `out` is disjoint
  from the inputs.
- **Post**: element `i` belongs to program `i / BLOCK_SIZE`.
- `meets_independent` combines the three.
- `consistent`: `exists_total_faithful` with `Platform.any`.
