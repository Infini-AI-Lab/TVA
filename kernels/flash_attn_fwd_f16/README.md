## Configuration covered

- **Non-causal** (`STAGE = 1`): `_attn_fwd_inner` runs once, with `STAGE = 3`, over
  `[0, N_CTX)`.
- **`float16`** (`FP8_OUTPUT = False`).
- **Hopper** (`IS_HOPPER = True`): `acc = acc * alpha[:, None]`, without the split of the
  accumulator.
- The descriptors are `[Z·H·N_CTX, HEAD_DIM]`, row-major, with zero padding. They are built either
  on the host (`TensorDescriptor`) or in the kernel (`tl.make_tensor_descriptor`, for
  `warp_specialize`). The model takes them as arguments.

The model (`attn_fwd`, `inner`) follows the source line by line.

- `qk * qk_scale - m_ij[:, None]` is `tl.mul` followed by the contractible `tl.subc`, which
  covers the `fma` the compiler may form.
- `l_i * alpha + l_ij` is `tl.mul_add`.
- `qk_scale = sm_scale ⊗ fl32(1.44269504)`, with the constant `0x3FB8AA3B`.

## Specification

`Spec K := Claim.Meets Inst.ok Pre Post K`. Write:

- `c = Inst.scale` for the device's `qk_scale`;
- `s(y, y') = Σ_{e<HD} q[y,e]·k[y',e]` for the exact score, from initial memory;
- `w_j = 2^(c·s(row i, row j))` for the weights, where `row j = (z·H + h)·N_CTX + j`.

`Post d init fin` says, for every head `(z, h)` and every query `i < N_CTX`:

- `M[row i]` is a finite `float32` with
  `|M − log₂ Σ_{j<N} w_j| ≤ errM` (`Mref`);
- for every `e < HEAD_DIM`, `O[row i, e]` is a finite `float16` with
  `|O − Σ_j w_j·v[row j, e] / Σ_j w_j| ≤ errO` (`Oref`);
- nothing outside `o` and `M` changes.

`2^(c·s) = e^(c·ln2·s)`, so `Oref` is `softmax(c·ln2 · q kᵀ) v`, and `c·ln 2 = sm_scale·(1 + O(2^-23))`.
The reference uses the device's scale `c`. It does not use the exact `sm_scale·log₂e`.

### The bounds

The constants are from `Numeric.lean` (`Err.*`), with `b = (N, HD, BN, R, V, C)`.

Units:

- `u = 2^-24`, `η = 2^-150` (`float32`);
- `u16 = 2^-11`, `η16 = 2^-25` (`float16`).

Assumed accuracies:

- `relE = relL = relDiv = 2^-22`;
- `absE = 2^-149`, `absL = 2^-22`, `absDiv = 2^-148`;
- `relDot K = (K+2)·2^-22`, `absDot K = (K+2)·2^-126`.

```
S  = HD·R²                     ε₁ = relDot(HD)·S + absDot(HD)        Q = S + ε₁
Mμ = C·Q·(1+u) + η             δ  = C·ε₁ + u·C·Q + η                 δx = δ + 6u·Mμ + 4η
κp = δx + relE·(1+δx)          γ  = 2·BN·u                           κs = κp + γ(1+κp)
νs = BN·absE·(1+γ) + 2·BN·η    δα = 2u·Mμ + η                        κα = δα + relE(1+δα)
Λmax = 2N   T = N/BN           νl = 3·absE·Λmax + 2νs + 4η
ρl0 = κs + 6u + 2νl            dl = 2κα + 12u + 2νl                  ρL = ρl0 + T·dl
κ16 = κp + u16(1+κp)           ν16 = absE(1+u16) + η16               θ = relDot(BN)
νa  = 3·absE·V·Λmax + 2η + 2V·BN·ν16 + absDot(BN)
ρv0 = V(κ16 + 2θ) + 2νa        dv = V(3κα + 2u + 3θ) + 2νa           ρV = ρv0 + T·dv
eO  = (ρV + V·ρL)/(1 − ρL)
errO = eO + relDiv(V+eO) + absDiv + u16((V+eO)(1+relDiv) + absDiv) + η16
eL  = 2ρL/(1 − ρL)             Lg = log₂(2N) + eL
errM = u(Mμ + (1+relL)·Lg + absL) + η + relL·Lg + absL + eL
```

How to read it:

- `δ` is how far a scaled score `c·s` can be from the device's value.
- `RowInv` keeps the running sum `l` within `(ρl0 + n·dl)·Λ` and the accumulator within
  `(ρv0 + n·dv)·Λ` after `n` blocks, where `Λ = Σ_{j<n·BN} 2^(c·s_j − m)`.

Sample values, with `N_CTX = 1024`, `HEAD_DIM = 64` and `C = 0.2`. For example `sm_scale = 1/8`
gives `c = 0.1803`. The values are evaluated from these formulas in exact rationals.

| `BN` | `R` | `V` | `ε₁` | `δ` | `ρL` | `ρV` | `errO` | `errO / V` | `errM` |
|---|---|---|---|---|---|---|---|---|---|
| 64 | 4 | 4 | 0.0161 | 3.24e-3 | 4.12e-3 | 0.0236 | 0.0422 | 1.06% | 8.28e-3 |
| 128 | 4 | 4 | 0.0161 | 3.24e-3 | 3.72e-3 | 0.0213 | 0.0383 | 0.96% | 7.49e-3 |
| 64 | 2 | 2 | 4.03e-3 | 8.09e-4 | 1.05e-3 | 5.08e-3 | 8.17e-3 | 0.41% | 2.11e-3 |
| 64 | 8 | 4 | 0.0645 | 0.0129 | 0.0164 | 0.0774 | 0.147 | 3.7% | 0.0334 |

Each row meets `Bnd.Ok`. The dominant term is `C·ε₁`, the score error of the `float16` dot under
`DotAcc` at the worst-case magnitude `S = HD·R²`. These are worst cases under the assumed
accuracies, not typical errors.

## Conditions

`Inst.ok`:

- `HEAD_DIM ∈ {16, 32, 64, 128, 256}`, `BLOCK_M ∈ {64, 128}`, `BLOCK_N ∈ {32, 64, 128}` and
  `BLOCK_N ≤ HEAD_DIM`. These are the tutorial's configurations and its `tl.static_assert`.
- `Z, H ≥ 1`, `Z·H < 2^16` (grid `y`), and `N_CTX > 0` with `BLOCK_M ∣ N_CTX` and `BLOCK_N ∣ N_CTX`.
  The kernel has no masks.
- `Z·H·N_CTX + BLOCK_M + BLOCK_N ≤ 2^31`. This covers the `int32` offsets, the loop bound and
  the TMA coordinates.
- Contiguous buffers: `q`, `k`, `v` and `o` have `Z·H·N_CTX·HEAD_DIM` elements, and `M` has
  `Z·H·N_CTX`. The `q`, `k`, `v` and `o` bases are 16-byte aligned.
- `o` and `M` are disjoint from each other and from `q`, `k` and `v`. The inputs may overlap.
- `c = sm_scale ⊗ fl32(log₂e)` is finite with `0 < c ≤ C`.
- `Bnd.Ok`:
  - `R ≤ 65504`, `0 < V ≤ 2^13`, `C·Q ≤ 2^60`;
  - `δx ≤ 1/4`, `κα ≤ 1/4`, `ρL ≤ 1/2`, `ρV ≤ V`;
  - `0 ≤ R`, `0 < C`, and the size facts `Inst.ok` already gives.

`Pre`:

- the five buffers are valid;
- every element of `q` and `k` is finite with `|x| ≤ R`;
- every element of `v` is finite with `|x| ≤ V`.

## Assumptions

These are the fields of `Assumptions K P`.

- `faithful`: `Compiler.Faithful`, the compiled kernel behaves as the model.
- `dotTotal`, `dotAcc`:
  - `tl.dot` of `float16` into `float32` has a result;
  - a `K`-term product is within `(K+2)·2^-22·(|acc| + Σ|a·b|) + (K+2)·2^-126` of
    `acc + Σ a·b`, for all finite operands (with room).
- `exp2Total`, `exp2Acc`:
  - `tl.math.exp2` is `ex2.approx.f32` without `.ftz`;
  - it is within `2^-22·2^x + 2^-149` of `2^x` (library issue L4).
- `exp2NegInf`: `exp2(-∞) = +0`. The first block uses it, since `m_i` starts at `-∞`.
- `log2Total`, `log2Acc`:
  - `lg2.approx.f32` is within `2^-22·|log₂x| + 2^-22` for positive finite `x`;
  - library issue L4 is to establish this.
- `divTotal`, `divFull`: `float32` `/` is `div.full.f32`, within `2^-22·|x/y| + 2^-148`.

`consistent`: `exists_total_faithful` with `Platform.ref`. The witness platform has relative
accuracy `2^-22`, absolute accuracy `2^-149` (`exp2`) or `2^-22` (others), and the special value
`exp2(-∞) = +0`.

## Proof

**`Numeric.lean`, one row.**

- `RowInv` after `n` blocks:
  - the running max `m` is finite and bounded by `Mμ`;
  - it is within `δ` above every scaled score seen, and within `δ` of one of them;
  - `l` and `acc` are within the relative bounds above of `Λ` and `A`.
- `row_step` proves one iteration. It covers:
  - `max`, `maximum` (with `-∞` for `n = 0`), `exp2` of the shifted scores and of `m − m'`;
  - the tree `sum`, the rescale, the `float16` conversion of `p`, `tl.dot(p, v, acc)` and
    `l·α + l_ij`.
- `row_out` proves the epilogue: `log2`, `m + log₂ l`, `acc / l` and the `float16` store.

**`FlashAttn.lean`, one program.**

- Program `p` handles head `p / (N/BM)` and rows `[p·BM, (p+1)·BM)`.
- Its tiles are read with `desc.load` (`safe_tile_load`).
- `qk_val` gives the score error `ε₁`.
- `safe_step` is one loop iteration: invariant `Inv`, memory unchanged, offsets at block `t`,
  and `RowInv` for every row.
- `safe_program` covers the whole body: `idiv`/`irem`, the `int32` offsets, `forRange` with
  `tripCount = N/BN`, the `M` store (`safe_store_buf`) and the `O` store (`safe_tile_store`).

**Footprints.** Program `p` writes `o` rows `[p·BM, (p+1)·BM)` and the same `M` rows. These are
disjoint across programs and from the inputs.

**`Post`.** `prog_of` maps `(z, h, i)` to program `(z·H+h)·(N/BM) + i/BM`, row `i % BM`.

`#print axioms main` and `#print axioms consistent` give `[propext, Classical.choice, Quot.sound]`.

## Narrowings

Not covered:

- causal attention (`STAGE = 3`, the masked on-band stage);
- `float8e5` (`FP8_OUTPUT`, the transposed `v`);
- non-Hopper code (the `acc0/acc1` split on Blackwell with `warp_specialize`, `BM = HD = 128`);
- `N_CTX` not a multiple of the blocks;
- non-contiguous strides;
- the backward kernels.

Limits of what is proved:

- The bounds are worst-case, through `S = HD·R²`.
- The inputs must be finite and bounded by `R` and `V`. There is no NaN or infinity propagation
  claim.
- The reference softmax uses the device's scale `c`.
