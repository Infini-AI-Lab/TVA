### `TVA.Dot8Chunk.chain_err`

```lean
TVA.Dot8Chunk.chain_err {ρ σ α : ℚ} (hρ : 0 ≤ ρ) (hσ : 0 ≤ σ) {s c m : ℕ → ℚ} {n : ℕ}
  (hstep : ∀ j < n, ∀ (Mj : ℚ), |s j| ≤ Mj → m j ≤ Mj → |s (j + 1) - (s j + c j)| ≤ ρ * Mj + σ * |s j + c j| + α)
```

exact partial sum `psum (s 0) c j`. Use it on the partial values of a `DotChunkAcc` fact.

```lean
TVA.Dot8Chunk.errL (σ α κ ρ' v : ℚ) (c a m : ℕ → ℚ) : ℕ → ℚ
```

The error after `j` chunks with the second arm of the minimum alone, each chunk charged
`κ·a j + ρ'·max |psum v c j| (m j)` (`a j` its exact magnitude) and the error so far grown by
`1 + ρ' + σ`: `errL 0 = 0` and

It bounds `errM` (`errM_le_errL`) where the chunks are small against the running sum.

### `TVA.sum_bcast_mul_err`

```lean
TVA.sum_bcast_mul_err {P : TVA.Platform} (hdot : TVA.Device.DotF32Ieee P) {fusion : Bool} {M K N : ℕ}
  {x : TVA.Tensor [M, K] TVA.F32} {y : TVA.Tensor [K, N] TVA.F32} {r : TVA.Tensor [M, N] TVA.F32}
  (hr :
    (∀ (i : Fin M) (j : Fin N),
        ∃ p,
          (∀ (k : ℕ) (hk : k < K), TVA.tl.MulRel TVA.DType.f32 (x.get2 i ⟨k, hk⟩) (y.get2 ⟨k, hk⟩ j) (p k)) ∧
            ∃ t, TVA.Tree.Covers K t ∧ TVA.Tree.Eval (TVA.AccAdd fusion TVA.DType.f32) p t (r.get2 i j)) ∨
      TVA.DType.f32.bytes ≤ 4 ∧
        16 ≤ M ∧
          16 ≤ N ∧
            P.dot { a := TVA.DType.f32, b := TVA.DType.f32, acc := TVA.DType.f32, precision := TVA.InputPrecision.ieee }
              x y (TVA.Tensor.full (TVA.DType.f32.ofBits 0)) r)
  (i : Fin M) (j : Fin N) (hx : ∀ (k : Fin K), TVA.FloatV.isFinite (x.get2 i k) = true)
  (hy : ∀ (k : Fin K), TVA.FloatV.isFinite (y.get2 k j) = true)
  (hroom :
    2 *
            ((1 + TVA.Format.binary32.u) * ∑ k, |TVA.FloatV.toRat (x.get2 i k) * TVA.FloatV.toRat (y.get2 k j)| +
              ↑K * TVA.Format.binary32.eta) +
          2 *
            TVA.Tree.errBound (3 * TVA.Format.binary32.u) (4 * TVA.Format.binary32.eta) (K - 1) (K - 1)
              ((1 + TVA.Format.binary32.u) * ∑ k, |TVA.FloatV.toRat (x.get2 i k) * TVA.FloatV.toRat (y.get2 k j)| +
                ↑K * TVA.Format.binary32.eta) +
        4 * TVA.Format.binary32.eta ≤
      TVA.Format.binary32.maxVal)
  (hroom' :
    (↑K + 2) * ∑ k, |TVA.FloatV.toRat (x.get2 i k) * TVA.FloatV.toRat (y.get2 k j)| + (↑K + 1) * 2 ^ (-149) ≤
      TVA.Format.binary32.maxVal) :
  TVA.FloatV.isFinite (r.get2 i j) = true ∧
    |TVA.FloatV.toRat (r.get2 i j) - ∑ k, TVA.FloatV.toRat (x.get2 i k) * TVA.FloatV.toRat (y.get2 k j)| ≤
      max (TVA.bcastTreeBound K (∑ k, |TVA.FloatV.toRat (x.get2 i k) * TVA.FloatV.toRat (y.get2 k j)|))
        ((↑K + 1) * 2 ^ (-23) * ∑ k, |TVA.FloatV.toRat (x.get2 i k) * TVA.FloatV.toRat (y.get2 k j)| +
```

whichever form the device runs (`hr`, as `safe_sum_bcast_mul` gives it): the products rounded and
summed along a tree (`sum_bcast_mul_tree_err`), or Triton's rewrite to an `ieee` `tl.dot`
(`Device.DotF32Ieee`, pass `h.dotF32Ieee`). The result is finite and within the larger of the two
bounds, `bcastTreeBound K B` and `(K+1)·2^-23·B + (K+1)·2^-149`, `B = Σ|x·y|`.
