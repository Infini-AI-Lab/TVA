### `TVA.tl.argCombine_tieLeft`

theorem · [lean/TVA/Proof/Rules/ArgReduce.lean:158](../../lean/TVA/Proof/Rules/ArgReduce.lean#L158)

```lean
TVA.tl.argCombine_tieLeft {β : Type} [TVA.CmpKey β] (key : β → ℤ)
  (hlt : ∀ (u v : β), TVA.CmpKey.lt u v = true ↔ key u < key v)
  (heq : ∀ (u v : β), TVA.CmpKey.eq u v = true ↔ key u = key v) (isMax : Bool) (a b : β × ℕ) :
  TVA.tl.argCombine isMax true a b =
    if (if isMax = true then key b.1 < key a.1 else key a.1 < key b.1) ∨ key a.1 = key b.1 ∧ a.2 < b.2 then a else b
```

With `tie_break_left`, on values ordered by `key`, `argCombine` keeps the pair whose value is
better (greater for `isMax`, smaller otherwise), and on equal values the smaller index.

### `TVA.Tree.eval_argCombine_first`

theorem · [lean/TVA/Proof/Rules/ArgReduce.lean:178](../../lean/TVA/Proof/Rules/ArgReduce.lean#L178)

```lean
TVA.Tree.eval_argCombine_first {β : Type} [TVA.CmpKey β] (key : β → ℤ)
  (hlt : ∀ (u v : β), TVA.CmpKey.lt u v = true ↔ key u < key v)
  (heq : ∀ (u v : β), TVA.CmpKey.eq u v = true ↔ key u = key v) (isMax : Bool) (g : ℕ → β) {t : TVA.Tree} {p : β × ℕ} :
  t.leaves.Nodup →
    TVA.Tree.Eval (fun a b c => c = TVA.tl.argCombine isMax true a b) (fun j => (g j, j)) t p →
      p.2 ∈ t.leaves ∧
        p.1 = g p.2 ∧
          ∀ j ∈ t.leaves,
            (if isMax = true then key (g j) ≤ key (g p.2) else key (g p.2) ≤ key (g j)) ∧
              (key (g j) = key (g p.2) → p.2 ≤ j)
```

**`tl.argmax`/`tl.argmin` with `tie_break_left` on keyed values.** Over any tree whose leaves
are distinct, the reduction of `(g j, j)` gives a leaf `p.2` whose value is a maximum (`isMax`)
or minimum of the leaves' values, and the smallest such leaf. With `t.Covers n` the leaves are
`0, …, n-1`, so `p.2` is the first index of the maximum (minimum).

```lean
  {d : TVA.DType} (b : TVA.Buf d) {ptrs : TVA.Tensor s (TVA.Ptr d)} {mask : Option (TVA.Tensor s Bool)}
  {upd : TVA.Idx s → d.Val → d.Val → Prop} {sem : TVA.MemSem} {sc : TVA.Scope} {g : TVA.Idx s → ℕ}
  {en : TVA.Idx s → Bool} (hA : b.Addrs (TVA.tl.addrs ptrs mask) g en)
  (hin : ∀ (i : TVA.Idx s), en i = true → g i < b.len)
  (hinj : ∀ (i j : TVA.Idx s), en i = true → en j = true → g i = g j → i = j)
  (htot : ∀ (i : TVA.Idx s) (o : d.Val), ∃ n, upd i o n) (hv : b.Valid m) (hW : b.elems (TVA.Buf.img g en) ⊆ W)
  (hRd : Disjoint (b.elems (TVA.Buf.img g en)) R) {k : TVA.Prog α}
  (hk :
    ∀ (m' : TVA.Mem),
      (∀ (i : TVA.Idx s),
          en i = true →
            ∃ old n, m.read d (b.ptr ↑(g i)).addr = some old ∧ upd i old n ∧ m'.read d (b.ptr ↑(g i)).addr = some n) →
        (∀ x ∉ b.elems (TVA.Buf.img g en), m' x = m x) →
          (∀ (x : ℤ), m x ≠ none → m' x ≠ none) → TVA.Safe E R (W \ b.elems (TVA.Buf.img g en)) Q m' k) :
  TVA.Safe E R W Q m do
    let _ ← TVA.tl.atomicWith ptrs upd mask sem sc
    k
```

**A tensor atomic on owned buffer elements, result unused** (`let _ ← tl.atomic_…`). Each
enabled lane updates its own element of `b` once, from the element's value before the atomic; the
rule gives each element's old and new value, and nothing outside the elements changes. The
elements are outside the read footprint, and the rest of the program may not touch them again.
The rule is about `tl.atomicWith`, which every `tl.atomic_*` is except `tl.atomic_add`: that is

it, apply `Safe.env`, then this rule with `upd := fun i => tl.addUpd E d (vals.get i)`.
