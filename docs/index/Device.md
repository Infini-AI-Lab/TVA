in `float32`: within `(K+2)·2^-22·L + (K+2)·2^-126` of `acc + Σ a·b`. Evidence:
`evidence/num-dot16-model` (a bit-exact model of both instruction paths, and adversarial inputs
at every `K` that compiles), `evidence/num-dot`.

### `TVA.Device.SumDepth`

def · [lean/TVA/Device/Sm90.lean:257](../../lean/TVA/Device/Sm90.lean#L257)

```lean
TVA.Device.SumDepth (P : TVA.Platform) : Prop
```

**The trees of a float reduction on sm_90 are balanced**: `P.sumDepth n ≤ ⌈log₂ n⌉`, so a
float reduction (`tl.sum` and the other float reductions, on any axis) over the `n` positions of
its axis combines them along a tree of depth at most `⌈log₂ n⌉` (`log₂ n` for the power of two
`n` of a Triton axis). Triton 3.8.0 lowers a reduction (`ReduceOpToLLVM.cpp`) as a balanced

`shfl.sync.bfly` over the lanes along the axis, then, through shared memory, the same butterfly

not stated for a reduction the compiler rewrites across loop iterations
(`OptimizeThreadLocality.cpp`). Evidence: `evidence/reduce-tree`.

### `TVA.Dot8Chunk.errB`

def · [lean/TVA/Device/Tolerance.lean:46](../../lean/TVA/Device/Tolerance.lean#L46)

```lean
TVA.Dot8Chunk.errB (ρ σ α v : ℚ) (c m : ℕ → ℚ) : ℕ → ℚ
```

The error allowed after `j` chunks when each chunk's rounding has relative error `ρ` on the
running value, `σ` on the new partial sum and absolute error `α`: `errB 0 = 0` and
`errB (j+1) = (1+ρ+σ)·errB j + ρ·max |psum v c j| (m j) + σ·|psum v c (j+1)| + α`

### `TVA.Dot8Chunk.errM`

def · [lean/TVA/Device/Tolerance.lean:55](../../lean/TVA/Device/Tolerance.lean#L55)

```lean
TVA.Dot8Chunk.errM (ρ σ α κ ρ' v : ℚ) (c a m : ℕ → ℚ) : ℕ → ℚ
```

A sharper chunk bound that takes, at each chunk, the smaller of the relative charge and a
charge `κ·a j + ρ'·(…)` proportional to the chunk's own size `a j`: with `X j = max |psum v c j| (m j)`,
`errM 0 = 0` and
`errM (j+1) = (1+σ)·errM j + min (ρ·(X j + errM j)) (κ·a j + ρ'·(X j + errM j)) + σ·|psum v c (j+1)| + α`.
It is at most `errB`.
