### `TVA.Recurrence.closed_Ico`

theorem · [lean/TVA/Proof/Recurrence.lean:59](../../lean/TVA/Proof/Recurrence.lean#L59)

```lean
TVA.Recurrence.closed_Ico (g U S : ℕ → ℝ) {m n : ℕ} (hmn : m ≤ n)
  (h : ∀ (t : ℕ), m ≤ t → t < n → S (t + 1) = g t * S t + U t) :
  S n = (∏ u ∈ Finset.Ico m n, g u) * S m + ∑ t ∈ Finset.Ico m n, (∏ u ∈ Finset.Ico (t + 1) n, g u) * U t
```

**The closed form, from trip `m`.** If `S (t + 1) = g t·S t + U t` for every trip
`m ≤ t < n`, then `S n = (Π_{m≤u<n} g u)·S m + Σ_{m≤t<n} (Π_{t<u<n} g u)·U t`. Use it for a state
carried from trip `m` (for example from one chunk boundary to the next); `closed` is the case
`m = 0`.

### `TVA.Recurrence.run`

def · [lean/TVA/Proof/Recurrence.lean:93](../../lean/TVA/Proof/Recurrence.lean#L93)

```lean
TVA.Recurrence.run (G c : ℕ → ℝ) (E₀ : ℝ) : ℕ → ℝ
```

**The running bound** of a linear recursion: `run G c E₀ 0 = E₀` and
`run G c E₀ (t + 1) = G t·run G c E₀ t + c t`. It bounds the error of a carried state (`perturb`,
with `G t ≥ |ĝ t|` and `c t` the error a trip adds); `run_le_sum`, `run_le_pow` and the closed
form `run_eq` evaluate it.

### `TVA.Recurrence.perturb`

theorem · [lean/TVA/Proof/Recurrence.lean:199](../../lean/TVA/Proof/Recurrence.lean#L199)

```lean
TVA.Recurrence.perturb {g gh U Uh S Sh e γ ε G : ℕ → ℝ} {n : ℕ} (hS : ∀ t < n, S (t + 1) = g t * S t + U t)
  (hSh : ∀ t < n, |Sh (t + 1) - (gh t * Sh t + Uh t)| ≤ e t) (hg : ∀ t < n, |gh t - g t| ≤ γ t)
  (hU : ∀ t < n, |Uh t - U t| ≤ ε t) (hG : ∀ t < n, |gh t| ≤ G t) :
  |Sh n - S n| ≤ TVA.Recurrence.run G (fun t => e t + ε t + γ t * |S t|) |Sh 0 - S 0| n
```

**The perturbed state.** The exact state follows `S (t + 1) = g t·S t + U t`; the computed
state `Ŝ` is within `e t` of `ĝ t·Ŝ t + Û t` at each trip, with `|ĝ t − g t| ≤ γ t`,
`|Û t − U t| ≤ ε t` and `|ĝ t| ≤ G t`, on the trips `t < n`. Then
`|Ŝ n − S n| ≤ run G (e + ε + γ·|S|) |Ŝ 0 − S 0| n`. A kernel takes `ĝ`, `Û`, `Ŝ` from its float
values (the decay and update it computed, the state after the trip's rounding) and `e`, `γ`, `ε`
from the float error lemmas; `perturb_le_sum` is the common case.

theorem · [lean/TVA/Proof/Recurrence.lean:368](../../lean/TVA/Proof/Recurrence.lean#L368)

```lean
TVA.Recurrence.exp_sub_mem_Ioc {A : ℕ → ℝ} {t n : ℕ} (htn : t ≤ n) (h : ∀ (u : ℕ), t ≤ u → u < n → A (u + 1) ≤ A u) :
  0 < Real.exp (A n - A t) ∧ Real.exp (A n - A t) ≤ 1
```

**Every factor of a decreasing cumulative sum is in `(0, 1]`**: if `A (u + 1) ≤ A u` on
`t ≤ u < n` (each gate `A (u + 1) − A u` is non-positive) and `t ≤ n`, then
`exp(A n − A t) ∈ (0, 1]`. It bounds the exact decay, not a computed one: a kernel with
`exp(cs[last] − cs[i])` uses it for the `|g t| ≤ G t` (with `G t = 1`) of `perturb'` followed by
`run_le_sum`, and for the `|g t| ≤ 1` of `abs_le_sum`. The computed decay `ĝ t` is a float that an
approximate `exp` may round above `1`: `perturb_le_pow` covers that case.

### `TVA.Recurrence.perturb_mat`

theorem · [lean/TVA/Proof/Recurrence.lean:451](../../lean/TVA/Proof/Recurrence.lean#L451)

```lean
TVA.Recurrence.perturb_mat.{u_1, u_2} {κ : Type u_1} {ν : Type u_2} {g gh γ G : ℕ → ℝ} {U Uh S Sh e ε : ℕ → κ → ν → ℝ}
  {n : ℕ} (hS : ∀ t < n, ∀ (k : κ) (v : ν), S (t + 1) k v = g t * S t k v + U t k v)
  (hSh : ∀ t < n, ∀ (k : κ) (v : ν), |Sh (t + 1) k v - (gh t * Sh t k v + Uh t k v)| ≤ e t k v)
  (hg : ∀ t < n, |gh t - g t| ≤ γ t) (hU : ∀ t < n, ∀ (k : κ) (v : ν), |Uh t k v - U t k v| ≤ ε t k v)
  (hG : ∀ t < n, |gh t| ≤ G t) (k : κ) (v : ν) :
  |Sh n k v - S n k v| ≤ TVA.Recurrence.run G (fun t => e t k v + ε t k v + γ t * |S t k v|) |Sh 0 k v - S 0 k v| n
```

**The perturbed matrix state** (`perturb` entry by entry): with scalar decays `g`, `ĝ`
(`|ĝ t − g t| ≤ γ t`, `|ĝ t| ≤ G t`) and per-entry errors `e t k v` (the trip's rounding) and
`ε t k v` (the update's), every entry has
`|Ŝ n k v − S n k v| ≤ run G (e·k·v + ε·k·v + γ·|S·k·v|) |Ŝ 0 k v − S 0 k v| n`.

### `TVA.Softmax.absErr_alpha`

```lean
  TVA.Softmax.absErr ε (TVA.Softmax.alpha m) η t =
```

theorem · [lean/TVA/Proof/Softmax/Error.lean:149](../../lean/TVA/Proof/Softmax/Error.lean#L149)

```lean
TVA.Softmax.accum {ε : ℝ} {α η X M Y Z x : ℕ → ℝ} {T : ℕ} (hε : 0 ≤ ε) (hα : ∀ t < T, 0 ≤ α t) (hx0 : x 0 = X 0)
  (hXM0 : |X 0| ≤ M 0) (hX : ∀ t < T, X (t + 1) = α t * X t + Y t) (hM : ∀ t < T, M (t + 1) = α t * M t + Z t)
  (hYZ : ∀ t < T, |Y t| ≤ Z t)
  (hstep :
    ∀ t < T,
      |x t - X t| ≤ TVA.Softmax.bound ε α η t (M t) → |x (t + 1) - (α t * x t + Y t)| ≤ ε * (α t * |x t| + Z t) + η t)
  (t : ℕ) : t ≤ T → |x t - X t| ≤ TVA.Softmax.bound ε α η t (M t)
```

**The running bound of a rescaled accumulation.** Let the exact state follow
`X (t+1) = α t·X t + Y t`, with a magnitude `M (t+1) = α t·M t + Z t`, `|Y t| ≤ Z t`, `α t ≥ 0`,
from `|X 0| ≤ M 0`. If the computed state starts at `x 0 = X 0` and, while its error so far is
within the bound, each trip is within `ε·(α t·|x t| + Z t) + η t` of `α t·x t + Y t`, then after
`t ≤ T` trips `|x t − X t| ≤ bound ε α η t (M t)`. The step may use the bound so far (to bound
`|x t|`, for an absolute error or the format's range). Use `l_err` or `acc_err` for the two states
of an online softmax, and this lemma for another rescaled state.

theorem · [lean/TVA/Proof/Softmax/Error.lean:279](../../lean/TVA/Proof/Softmax/Error.lean#L279)

```lean
      TVA.Softmax.bound ε (TVA.Softmax.alpha mh) η t (TVA.Softmax.asum s (fun u j => |v u j|) B (mh t) t)
```

**The accumulator with errors** (one output column). With the computed references `m̂` and
accumulator `âcc` (`âcc 0 = 0`): if each trip is within
`ε·(α t·|âcc t| + Σ_{j ∈ B t} exp (s t j − m̂ (t+1))·|v t j|) + η t` of
`α t·âcc t + Σ_{j ∈ B t} exp (s t j − m̂ (t+1))·v t j` (`α = alpha m̂`), then for `t ≤ n`
`|âcc t − asum s v B (m̂ t) t| ≤ bound ε (alpha m̂) η t (asum s |v| B (m̂ t) t)`.

theorem · [lean/TVA/Proof/Softmax/Error.lean:439](../../lean/TVA/Proof/Softmax/Error.lean#L439)

```lean
  TVA.Softmax.asum s v B m t / TVA.Softmax.lsum s B m t =
    TVA.Softmax.wavg ((Finset.range t).sigma B) (fun x => s x.fst x.snd) fun x => v x.fst x.snd
```

**The ratio is the softmax-weighted sum**, whatever the reference `m`:
`asum m t / lsum m t = wavg` over the pairs (trip, lane) seen in `t` trips.

### `TVA.Softmax.l_eq`

theorem · [lean/TVA/Proof/Softmax/Exact.lean:235](../../lean/TVA/Proof/Softmax/Exact.lean#L235)

```lean
TVA.Softmax.l_eq.{u_1} {ι : Type u_1} {s : ℕ → ι → ℝ} {B : ℕ → Finset ι} {m α l : ℕ → ℝ} {n : ℕ} (h0 : l 0 = 0)
  (hα : ∀ (t : ℕ), 0 < t → t < n → α t = Real.exp (m t - m (t + 1)))
  (hl : ∀ t < n, l (t + 1) = α t * l t + ∑ j ∈ B t, Real.exp (s t j - m (t + 1))) (t : ℕ) :
  t ≤ n → l t = TVA.Softmax.lsum s B (m t) t
```

**The exact running sum.** A sequence `l` with `l 0 = 0` and
`l (t+1) = α t·l t + Σ_{j ∈ B t} exp (s t j − m (t+1))`, where `α t = exp (m t − m (t+1))` for
`t > 0` (`α 0` is free: it multiplies `l 0 = 0`), is `lsum s B (m t) t` for every `t ≤ n`, for any
references `m`. Use it for a kernel's `l` computed without rounding (or as the reference the
rounded one is compared with).

### `TVA.Softmax.abs_exp_round_le`

theorem · [lean/TVA/Proof/Softmax/Exp.lean:92](../../lean/TVA/Proof/Softmax/Exp.lean#L92)

```lean

  |Real.exp y - Real.exp x| ≤ 2 * (u * K + δ) * Real.exp x + 2 * (u * K + δ) * Real.exp (-(K / 2))
```

**The exponential of a rounded non-positive argument.** If `x ≤ 0` and `y` is within
`u·|x| + δ` of `x` (one rounding of `x`: relative `u ≤ 1/2`, absolute `δ ≥ 0`), then for any

`|x| ≤ K`, absolute beyond. Use it for a weight `exp(s − m)` computed from a rounded `s − m` (or
`exp2` of it, through `two_rpow_eq_exp`), choosing `K` to balance the two terms.
