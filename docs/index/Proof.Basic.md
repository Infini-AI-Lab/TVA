### `TVA.independent`

theorem · [lean/TVA/Proof/Compose.lean:255](../../lean/TVA/Proof/Compose.lean#L255)

```lean
TVA.independent {k : TVA.Kernel} {L : TVA.Launch} {E : TVA.Env} {init : TVA.Mem} {R W : Fin L.size → Set ℤ}
  {Q : Fin L.size → TVA.Mem → Prop}
  (hsafe : ∀ (i : Fin L.size), TVA.Safe E (R i) (W i) (fun x m => Q i m) init (k.body (L.ctx ↑i)))
  (hdisj : ∀ (i j : Fin L.size), i ≠ j → Disjoint (W i) (R j ∪ W j)) (hRW : ∀ (i : Fin L.size), Disjoint (R i) (W i)) :
  TVA.WellBehaved E k L init ∧
    ∀ (o : TVA.Outcome),
      TVA.Outcomes E k L init o →
        ∃ fin,
          o = TVA.Outcome.ok fin ∧
            (∀ (i : Fin L.size), ∃ m, Q i m ∧ ∀ x ∈ R i ∪ W i, fin x = m x) ∧
              ∀ (x : ℤ), (∀ (i : Fin L.size), x ∉ W i) → fin x = init x
```

**Independent programs.** Programs that are each safe alone from the initial memory, with
footprints no other program writes into and read footprints disjoint from their own write
footprints, make a well-behaved launch. Its only outcomes are normal ends whose memory agrees
with a memory satisfying each program's `Q i` on that program's footprint, and with the initial
memory where no program writes. `correct_of_safe` states it as `Correct`.

### `TVA.correct_of_safe`

theorem · [lean/TVA/Proof/Correct.lean:36](../../lean/TVA/Proof/Correct.lean#L36)

```lean
TVA.correct_of_safe {E : TVA.Env} {k : TVA.Kernel} {L : TVA.Launch} {init : TVA.Mem} {Post : TVA.Mem → Prop}
  (R W : Fin L.size → Set ℤ) (Q : Fin L.size → TVA.Mem → Prop) (hvalid : L.Valid)
  (hsafe : ∀ (i : Fin L.size), TVA.Safe E (R i) (W i) (fun x m => Q i m) init (k.body (L.ctx ↑i)))
  (hdisj : ∀ (i j : Fin L.size), i ≠ j → Disjoint (W i) (R j ∪ W j)) (hRW : ∀ (i : Fin L.size), Disjoint (R i) (W i))
  (hpost :
    ∀ (fin : TVA.Mem),
      (∀ (i : Fin L.size), ∃ m, Q i m ∧ ∀ x ∈ R i ∪ W i, fin x = m x) →
        (∀ (x : ℤ), (∀ (i : Fin L.size), x ∉ W i) → fin x = init x) → Post fin) :
  TVA.Correct E k L init Post
```

**The endpoint of a claim's proof.** The launch `L` of `k` from `init` is `Correct` for the
specification `Post` when it is valid, each program `i` is `Safe` alone from `init` with footprints
`R i`, `W i` and post-condition `Q i`, no program writes into another's footprint, no program reads
what it writes, and any final memory that agrees with some `Q i`-memory on each program's footprint
and with `init` where no program writes satisfies `Post`.

Use it as the last step of `theorem main : claim.Holds`:
```
theorem main : claim.Holds := by
  intro P hP d hd init hpre
  refine correct_of_safe (R d) (W d) (Q d init) (launch_valid hd) (fun i => ?_) ?_ ?_ ?_
  · -- program `i`: rewrite the body (`k.body (L.ctx i)`) and walk it with the rules
    exact safe_program hd hpre i
  · -- `∀ i j, i ≠ j → Disjoint (W d i) (R d j ∪ W d j)`
    …
  · -- `∀ i, Disjoint (R d i) (W d i)`
    …
  · -- `∀ fin, (∀ i, ∃ m, Q d init i m ∧ ∀ x ∈ R d i ∪ W d i, fin x = m x) →`
    -- `  (∀ x, (∀ i, x ∉ W d i) → fin x = init x) → claim.Post d init fin`
    intro fin hloc hfr
    …
```
To read a value back in the last goal, take the program `i` that wrote it, get its memory `m`
from `hloc i`, and move the read with `Mem.read_congr` (the element lies in `W i`).

### `TVA.Safe.stepT`

theorem · [lean/TVA/Proof/Safe.lean:158](../../lean/TVA/Proof/Safe.lean#L158)

```lean
TVA.Safe.stepT {E : TVA.Env} {R W : Set ℤ} {α : Type} {Q : α → TVA.Mem → Prop} {m₀ m : TVA.Mem} {p : TVA.Prog α}
  (h : TVA.Safe E R W Q m₀ p) (hag : ∀ x ∈ R ∪ W, m x = m₀ x) {m' : TVA.Mem} {p' : TVA.Prog α} {e : TVA.Event}
  (hs : TVA.Step E m p (TVA.Out.next m' p' e)) :
  e.reads ⊆ R ∪ e.writes ∧
    e.writes ⊆ W ∧
      TVA.Step E m₀ p (TVA.Out.next (m₀.mix m' e.writes) p' e) ∧ TVA.Safe E R (W \ e.writes) Q (m₀.mix m' e.writes) p'
```

memory `m` that agrees with `m₀` on the footprint. Every step it takes, an atomic performed later
(`Step.defer`) included, is a normal step that reads inside `R` or inside what it writes, and
writes inside `W`. The same step is possible from `m₀`, giving `m₀` with the step's writes, and
the rest is safe there with the written bytes removed from the write footprint.

```lean
TVA.Step.transfer {α : Type} {E : TVA.Env} {m m₀ m' : TVA.Mem} {p p' : TVA.Prog α} {e : TVA.Event}
  (h : TVA.Step E m p (TVA.Out.next m' p' e)) (hag : ∀ x ∈ e.reads ∪ e.writes, m₀ x = m x) :
  TVA.Step E m₀ p (TVA.Out.next (m₀.mix m' e.writes) p' e)
```

**Transfer of one step.** A step can be taken the same way in any memory that agrees on the
bytes its event reads and writes; the result is that memory with the step's writes.
