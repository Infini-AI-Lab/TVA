```lean
TVA.safe_store_block {d : TVA.DType} {p B n : ℕ} {E : TVA.Env} {R W : Set ℤ} {α : Type} {Q : α → TVA.Mem → Prop}
```

```lean
  {R W : Set ℤ} {α : Type} {Q : α → TVA.Mem → Prop} {m : TVA.Mem} (b : TVA.Buf d)
  {ptrs : TVA.Tensor [BM, BN] (TVA.Ptr d)} {mk : Option (TVA.Tensor [BM, BN] Bool)} {vals : TVA.Tensor [BM, BN] d.Val}
  (hp : ∀ (i : Fin BM) (j : Fin BN), ρ i < M → κ j < N → ptrs.get2 i j = b.ptr ↑(e + ρ i * s0 + κ j * s1))
```

```lean
  (hκ : ∀ (j j' : Fin BN), κ j < N → κ j' < N → κ j = κ j' → j = j') (hv : b.Valid m)
  (hW : b.tileAt e s0 s1 ρ κ M N ⊆ W) {k : Unit → TVA.Prog α}
```

`r0 + i`), so that the lanes write distinct elements. The rest of the program may not write the
tile again.

```lean
  (hfit1 : (N - 1) * s1 < 2 ^ (w' - 1)) (i : Fin BM) (j : Fin BN) :
  ρ i < M → κ j < N → (base + rows.col BN * a0 + cols.row BM * a1).get2 i j = b.ptr ↑(e + ρ i * s0 + κ j * s1)
```

**The pointers of a 2-D tile on the enabled lanes, one term at a time**,
`base + rows[:, None] * a0 + cols[None, :] * a1` (the row term in width `w`, the column term in
width `w'`), when `(M - 1) * s0 < 2^(w-1)` and `(N - 1) * s1 < 2^(w'-1)`.
