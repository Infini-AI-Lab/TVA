Fix: drop "or never"; say that a call that returns without an error and whose grid never runs (the launcher's skip) ends `ok` with memory unchanged, which `Launch.Valid` excludes; and describe the non-execution as a host call that only records the grid for a run made by a later call, that run being the execution.
